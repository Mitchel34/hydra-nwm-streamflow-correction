# Provenance and disclosure scope

The accompanying summary is derived from preserved local independent data-review and
terminal receipts dated 14 October 2026. SHA256 values identify the exact evidence bytes;
they are not substitutes for source access, replication, external review or immutability.
The public repository does not contain the private research inputs or full raw responses.

Local evidence labels used in `data-review-summary.json`:

- `candidate_manifest`: inventories candidate/soil output identities and source lineage.
- `independent_acceptance`: accepts that exact manifest for its stated data contract.
- `independent_result`: complete local independent reconstruction/check result.
- `terminal_receipt`: records completion, limitations and the no-training disposition.

The manifest's author-time status predates independent acceptance. Acceptance must be
read from the separately hash-bound independent record, not inferred from that earlier
status string. Current metadata checks confirmed the acceptance binding and residency;
the entire raw reconstruction was not rerun for this publication.

Summary numbers were checked against those evidence records before publication. Scientific
interpretation remains limited by the caveats in `data-contract.md`. A local independent
review is not an external peer-reviewed publication. No prediction arrays, learned metrics
or fitted checkpoints have been produced for the corrected four-model comparison.

This release adds only allowlisted documentation and aggregate data-review fields.
Private datasets, raw input files, provider job identifiers, credentials, personal notes,
absolute machine paths and unrelated projects are excluded. It does not add a license,
modify CI configuration, alter training authority or overwrite historical results.
