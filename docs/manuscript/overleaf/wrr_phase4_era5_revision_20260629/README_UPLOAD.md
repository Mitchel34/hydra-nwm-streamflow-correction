# WRR Phase 4 ERA5 Overleaf Upload Bundle

This folder is the self-contained Overleaf upload bundle for the Phase 4 ERA5 revision of the Hydra WRR manuscript.

- Upload this folder's contents to Overleaf.
- The Overleaf entry point is `main.tex`.
- Optional supplement entry point: `visual_supplement_tables.tex`.
- This bundle was derived from `docs/manuscript/overleaf/wrr_phase3_revision_20260506/`.
- The package includes the manuscript source, bibliography, AGU class file, lock artifacts, and figures referenced by the main manuscript or supplement.
- Older folders under `docs/manuscript/overleaf/` and `docs/manuscript/overleaf_wrr_project.zip` are archival and are not the current submission package.
- Local compile was not run in this workspace because no TeX engine was available; compile in Overleaf or another TeX environment.

Included root-level files:

- `main.tex`
- `refs.bib`
- `agujournal2019.cls`
- `trackchanges.sty`
- `visual_supplement_tables.tex`
- `README_UPLOAD.md`

Included directories:

- `locks/`
- `figures/`
